# Future Crop — Streamlit Dashboard

[![DataCrafted](https://img.shields.io/badge/Store-DataCrafted-red)](https://payhip.com/DataCrafted)

Agricultural data analysis dashboard built with **Streamlit** and **Python**.

## Overview

Analyze crop data, visualize trends, and make data-driven agricultural decisions — all from an interactive web dashboard.

## Tech Stack

- **Python 3.11**
- **Streamlit** — interactive web app framework
- **Pandas / Plotly** — data analysis & visualization

## Getting Started

```bash
pip install -r requirements.txt
streamlit run future_crop_challenge.py
```

## Data

Includes dummy data for exploration. Replace with your own CSV for real analysis.
